## 1. 一条被反复验证的病理：语言先验压过视觉证据

大量 VLM 在**图像被替换/遮挡/打乱**后答案几乎不变。这说明模型在做"语言常识题"而不是"看图题"。

| 症状 | 诊断方法 | 常见对策 |
| :-- | :-- | :-- |
| 不看图也能答对 | 图像消融 / 反事实图像 | 训练时遮掉答案泄露文本、构造视觉困难负样本 |
| 细粒度感知差 | MMVP、BLINK 类配对样本 | 高分辨率、视觉对比学习、感知专项数据 |
| 长链推理跑偏 | 中间步骤人工检查 | 过程奖励、分阶段监督 |
| 过度思考 | token 数与正确率的相关性 | thinking budget、早停、难度自适应 |

> **这是本仓库所有赛道的共同出发点**：latent 推理想绕过文本瓶颈，agentic 视觉想主动补足证据，视频推理想延长证据窗口，效率赛道想砍掉冗余思考——本质上都在对付同一个病。

## 2. 训练范式演进

```
SFT（图文指令）
   └─▶ 冷启动 CoT（人工/合成推理链）
          └─▶ RLVR（可验证奖励：答案对不对）
                 └─▶ 过程奖励 / 细粒度奖励（每一步对不对）
                        └─▶ 测试时扩展（多采样、自我一致性、搜索、验证器）
                               └─▶ 隐式推理（连文字都省掉）← 见 latent 赛道
```

**RLVR 在多模态上的三个特殊困难**：
1. 奖励稀疏——视觉任务的答案往往短（一个数字、一个选项），信号弱；
2. 奖励可被 hack——模型学会从选项分布、图像元信息里猜；
3. 奖励与感知脱钩——答案对但理由错（"蒙对了"），需要过程级验证。

## 3. Omni-modal 与统一建模

| 方向 | 目标 | 难点 |
| :-- | :-- | :-- |
| Any-to-any | 任意模态进、任意模态出 | 输出侧生成质量与理解能力互相拖累 |
| 原生交错（interleaved） | 文本/图像/音频在同一序列里自然交替 | 位置编码、模态对齐、训练数据构造 |
| 统一 tokenizer | 用一个离散码本表示所有模态 | 视觉保真度 vs 序列长度 |

## 7. 开放问题

- 视觉奖励模型能否像文本 RM 一样可靠？现在多依赖规则/答案匹配。
- 测试时扩展在多模态上是否同样有效？还是很快饱和？
- 数据配方：感知数据、推理数据、GUI 数据的最优配比无人给出通解。
- 评测污染：网络图文语料几乎必然包含评测集，分数通胀严重。
